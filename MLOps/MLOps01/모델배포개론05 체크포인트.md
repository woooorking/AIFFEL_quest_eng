### ✅ 체크포인트

1. 정규화에서 학습 데이터의 통계를 테스트 데이터에도 사용하는 이유는 무엇입니까?
- 학습 데이터의 기준을 유지해야 하기 때문
2. 모델 가중치 외에 **함께 저장해야 하는 것**은 무엇이고, 왜 필요합니까?
- 학습 데이터에서 나온 전처리 파라미터를 같이 저장해야함. 학습할때 똑같은 기준으로 정규화 해야하는데 평균, 표준편차 값 모르면 수행못하기 때문
3. `HousingPredictor.predict()`에서 피처를 `self.feature_names` 순서로 배열하는 이유는?
- 순서가 바뀌면 잘못 연산할 수 있어서 처음 학습할때 약속한 자리대로 놔야함.

### ✅ 체크포인트

1. `HousingRequest`에서 `Latitude`에 `ge=32, le=42` 제한을 넣은 이유는?
- 캘리포니아 위도 값에 해당하는 거만 작동하게 만듦
2. `request.model_dump()`는 어떤 역할을 합니까?
- pydantic에 있는 데이터를 딕셔너리 형태로 꺼내주는 역할
3. `run_in_executor`를 사용하지 않으면 어떤 문제가 발생할 수 있습니까?
- 안쓰면 계산 끝날때까지 멈춰있는 문제 발생함. 그래서 run in execuor를 사용해서 스레드풀에 넘겨주면 계속 사용자가 요청하는걸 처리할 수 있음
